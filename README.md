A simple web-based Student Management System built using HTML, CSS, and JavaScript.
The application allows users to add student details and view them dynamically in a table.

## How to Run the Project Locally

1. Clone the repository  
git clone https://github.com/AshInnovates/student-management-system.git


2. Open the project folder in Visual Studio Code  

3. Open `index.html`  
- Right-click and select *Open with Live Server*  
- Or open the file directly in a web browser  

---

## How It Works

- The user enters student details in the form  
- On clicking **Add Student**, JavaScript validates the input  
- A new row is dynamically added to the table using DOM manipulation  
- Data is stored temporarily in memory (no database used in this version)
